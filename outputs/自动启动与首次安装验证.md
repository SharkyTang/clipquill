# v0.1.5 自动启动与首次安装验证

日期：2026-10-14。范围：本机 Apple Silicon Mac、macOS 26.6.2、Google Chrome。

## 交付结果

- 点击“提取文案”自动检查服务；未运行时由已安装的本地助手后台启动，随后继续当前视频处理。服务已运行时复用。
- 启动失败提供“重试启动并提取”，保留原任务的链接、所选作品、清晰度和术语。下载视频仍独立工作。
- 完整安装包内置可移动 Python 3.12、固定依赖、FFmpeg/ffprobe、Whisper 及其非系统动态库。安装程序自动下载固定版本模型并校验 SHA-256，自动配置 Chrome 配对，不需要用户准备环境、Homebrew、编译器或填写扩展 ID。
- 安装到当前用户的 `Library/Application Support/ClipQuill`，资源不链接到原项目。无需手动终端窗口，不添加登录启动任务。
- 本机原扩展身份保留，26 个旧任务记录和 241 个旧结果文件已复制到安装版，原文件与浏览器草稿不删除。

- 安装包 Python、ASR 导入、FFmpeg/ffprobe 和 Whisper 在仅包含系统目录的 PATH 下运行通过。非系统 Mach-O 依赖已收集并重定位，运行不依赖原 Homebrew 路径。

## 本地原生协议与识别实测

使用安装版实际的 stdin/stdout 原生消息协议，两个并发冷启动请求只创建一个服务，另一个请求复用。原生消息宿主退出后服务继续运行。未配对扩展、普通网站来源被拒绝；端口冲突不会终止其他程序。

隔离目录处理已有作品 `7691611431967718755`，约 127.8 秒视频，得到 1,047 字、70 个片段，本地处理 17.063 秒。已取得 TXT/SRT 数据及原音，并验证服务重启后仍可恢复结果。临时隐藏该隔离环境的解释器，得到真实 `INSTALLATION_INCOMPLETE` 启动错误；还原后重试成功。以上原生协议测试不冒充 Chrome 页面操作。

原始本机记录：`work/auto-start-validation.json`，隔离结果位于 `work/auto-start-validation-helper-v2/`，不随 Git 提交。

## 真实 Chrome 人工验收

浏览器自动化的 URL 安全策略拒绝访问 `chrome-extension://`。最终由用户重新加载原插件、关闭旧工具页再打开，直接点击“提取文案”进行验证。

第一次人工验证报告“此本地服务仅供已配置的扩展使用”。已核对：实际服务已启动，原扩展 ID 与安装配对一致，显式携带配对 Origin 的请求正常，缺少 Origin 的请求被拒绝。新增 loopback host permission 会改变 Chrome 的跨源请求处理；移除该权限，沿用普通 CORS 与严格来源校验后修复。未放宽服务来源限制。

为验证真实冷启动，修复后先停止本次安装的空闲服务，再由用户重新加载插件并直接提取。用户明确确认“这次可以自动启动并完成提取”。后台证据同步核对：

- 原空闲服务 PID 46719 已停止，点击后创建新服务 PID 47162。
- 新任务 `7d00ba7c0ac640db9b54270f357b851b`，作品 `7668311202589691187`，状态 `complete`。
- 结果 3,592 字、287 个语音片段，本地处理 47.698 秒。
- 原扩展目录与已安装目录的最终 manifest 一致。

因此本机真实 Chrome 的“服务停止 → 点击提取 → 自动后台启动 → 完成当前视频提取”已通过人工验收，并有实际任务记录支持。没有声称自动工具访问过扩展页面，也没有重新要求用户准备模型。

## 安装包与限制

完整安装包：`outputs/ClipQuill-v0.1.5-mac-arm64.zip`。包含 9,499 个已校验的资源文件，约 187.8 MiB；模型首次另行下载约 4.02 GiB。扩展单独包：`outputs/douyin-independent-extension-v0.1.5.zip`。最终 ZIP 完整性、清单 SHA-256 和源码一致性检查通过。

安装程序不改系统 Python 或 shell 配置。原生助手只接受已配对扩展和固定启动命令；本地服务仅监听 `127.0.0.1:8766`，输入、回听与旧结果的限制保留。模型推理离线进行，自动识别仍需核对。

其他电脑的完整首次安装、Windows、Intel Mac、其他浏览器、旧 macOS、Developer ID 签名、公证及对外发行的许可完整性尚未验收。当前 ZIP 是本机验证的 Mac 开发版，不能宣称适用于所有用户。浏览器尚未商店上架，首次加载开发版扩展仍需用户在 Chrome 中操作。

依赖与模型固定记录：`scripts/asr-requirements.lock.txt`、`packaging/models.lock.json`，包内许可证与二进制来源记录保留。安装包构建脚本：`scripts/build_helper_installer.py`；独立运行验证脚本：`scripts/verify_auto_start.py`。
