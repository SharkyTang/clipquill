# 抖音视频独立导出：本地 Chrome 扩展原型

## v0.1.3 视频复用修复（2026-10-13）

“提取文案”、处理已打开作品和失败重试会先检查“下载 / 抖音独立导出”中的已有视频，核对作品 ID、兼容 MP4 规格和实际文件大小。完整文件直接交给本地识别；没有匹配的完整文件时才下载。过去版本保存的文件、Chrome 自动增加的重复文件名、重新打开工具页或重启服务后的文件都可复用，不依赖浏览器下载历史或仍有效的 CDN 链接。

清晰度是新下载时的偏好。提取文案已有完整兼容视频时会复用该文件，并显示实际清晰度，不因切换偏好重复下载。“下载视频”按钮仍按所选清晰度保存视频。识别失败、服务繁忙或无法连接不会自动重复下载；文件在检查后丢失或被截断时会重新检查，必要时补下载一次。旧稿仍保留到新的识别结果完成。

更新步骤：在 Chrome 扩展管理中对现有目录点击“重新加载”，关闭旧工具页再重新打开；关闭原本地文案服务窗口，再双击项目 `outputs/启动本地文案服务.command`。扩展会检查服务是否支持视频复用，旧服务会提示重启，不会默默退回每次下载。仍使用原扩展目录和身份，无需清理存储。

当前包：`outputs/douyin-independent-extension-v0.1.3.zip`。v0.1.2 和更早的包保留原样。39 项 JavaScript、37 项 Python 检查通过，覆盖复用、识别失败重试、文件丢失与大小不符、其他作品、符号链接、服务错误和检查后文件变化。本机已有 720p、27,594,766 字节视频的文件查找与复用核对通过。新流程尚未在真实 Chrome 界面重新验收；下方 v0.1.2 的真实界面验收保留为历史记录。

## v0.1.2 简化版历史记录（2026-10-13）

阶段 0/1 已在本机真实 Chrome 完成十条作品的下载与提取，以及默认折叠、回听、编辑、复制、恢复、窄窗口、键盘、失败与重试。视频全部完整解码、SHA 与服务输入一致；八条口播有有效当前 TXT/SRT，两条纯音乐的“啊/嗯”如实记录为误识别，源零时长字幕拒绝导出，不承诺文案完全准确。v0.1.2 修正整行空白漏提示和媒体毫秒末端误拒绝，32 项 JavaScript 检查通过。用户明确确认 0.1.2 后，两处导出边界及刷新前后两种文件实核通过；早前管理版本混用记录保留，不宣称十条都在同一最终版本逐项重跑。十二张真实截图已原样归档，默认、结果操作、展开回听、实际 Chrome 扩展地址与窄窗口均已核对。本机可执行的阶段 0/1 验收已收尾；精确 CSS 窗口宽度未测量，缺失设备、国内网络、干净安装及未触发异常保留待验证。原有 28 项 Python 检查作为未变服务的基线。自动工具禁止访问扩展页，真实界面由用户操作。阶段 2 及后续未开始；没有公开发布或上架。

- 主界面保留分享链接、下载视频、提取文案和可编辑的全文、复制、TXT/SRT。
- 清晰度、术语位于“辅助选项”；模型、片段、人工确认和分歧信息位于“回听与细致校对”，默认折叠。
- 旧术语和旧校对草稿保留。旧术语必须手动填入并启用，换链接、换所选作品、刷新或提交任务后默认停用。
- 原始识别文件不变。当前稿使用独立存储，复制与 TXT 使用全文编辑框中的当前内容，不要求人工确认。
- 改字保留原区间；删除完整行保留剩余行的时间；删除段间换行或跨段替换会合并涉及的原区间；新增文字归入所在区间。不会重新对齐或生成新时间。合并后回听区也展示合并后的当前稿。
- 没有有效原时间的旧任务、空稿，或含 SRT 分隔符与空白行的文本，会说明不能安全导出 SRT，仍可复制与导出 TXT，不会输出旧字幕。清空文字会保留该行；需要明确删除整行及换行，或合并相邻段。字幕与媒体末端均按一毫秒精度核对，原时间端点不改写。
- 当前稿及已完成结果保存在扩展本机存储。重新打开可直接恢复最后完成的当前稿；旧版尚未缓存的结果需点击“恢复上次文案”。回听需要本地服务。卸载或清理扩展存储前请导出。
- 等待、失败、完成与重试有独立提示。服务未启动时可展开启动说明并检查连接；失败后已有当前稿继续保留，下载仍可用。

请优先更新现有目录后在 Chrome 扩展管理中点击“重新加载”，再关闭旧工具页并重新打开。使用同一目录才能保留当前扩展身份与草稿。ZIP 解压到新的目录后可能改变扩展 ID，现有服务只允许配置的 ID；身份变化需要按原服务说明处理，此处没有实现阶段 2 的自动配对。

## 文案精校版（2026-10-12 更新）

粘贴分享链接即可在本机识别文案，不依赖轻抖。默认使用 Qwen3-ASR 1.7B，时间对齐由 Qwen3 ForcedAligner 完成，Whisper Turbo 对照识别提示分歧。支持可选术语、逐句原音回听、修改、确认、草稿恢复和同步 TXT/SRT 导出。模型稿始终与校对稿分开，不能保证 100% 准确。

原 300 秒样本真实 Chrome 流程完成，本地处理 23.861 秒。多处中文词语与英文专名改善，仍有“成片→成天”等错误；错误提示不是准确率。详见项目 outputs 中的“文案精度优化验证.md”和“文案提取使用说明.md”。

更新没有增加 Chrome 权限；重新打开工具页即可。重启电脑后先双击项目 `outputs/启动本地文案服务.command`。本地服务 `scripts/transcription_bridge.py` 调用项目专用 Python 环境中的 `scripts/transcribe_accurate.py`。

服务仅监听 `127.0.0.1:8766`，仅接受配置的扩展 Origin 和准确 Host。视频查找只检查扩展下载目录中指定作品 ID、规格和大小匹配的普通 MP4，不接受外部目录或符号链接；实际识别仍再次核对文件并验证音轨与时长。回听接口只能读取已完成任务产生的音频。没有任意文件读取或 URL 抓取接口。

校对草稿保存在扩展本地存储；卸载或清理扩展数据前请导出。ZIP 仅含扩展，模型、Python 环境和音频工具在本项目中，不能单独拷贝到其他电脑运行。当前验证平台为本机 Apple Silicon Mac。

这是独立实现，没有轻抖接口、账号、密钥或后端依赖。原型只获取正常抖音页面提供的 H.264 MP4 播放文件，不进行画面擦除，不承诺所有视频没有水印。

## 加载与使用

1. 在 Chrome 打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择包含本 README 和 manifest.json 的文件夹。
3. 从扩展菜单打开“抖音视频独立导出 · 本地原型”。
4. 粘贴分享链接，选择优先清晰度，点击“下载视频”或“提取文案”。
5. 如果页面需要登录、验证或没能停留在原作品，请点“打开待处理的抖音页面”，自行正常完成后再从“使用已经打开的作品页面”选择目标作品重试。不会自动解决验证码或绕过拒绝。

默认保存到系统“下载 / 抖音独立导出”文件夹。工具页在下载期间需保持打开，以展示最终校验状态；关闭工具页不会取消已经交给 Chrome 的下载。

## 权限用途

| 权限 | 用途 |
|---|---|
| `scripting` | 由按钮触发，读取目标抖音页面中 `RENDER_DATA` 的作品及媒体字段 |
| 抖音两个站点的访问权限 | 正常打开分享链接、读取作品页面。浏览器按自身规则处理页面会话；扩展代码不读取、复制或自行注入 Cookie |
| `downloads` | 发起下载，并查询本工具本次发起的下载是否完成、大小是否匹配 |

代码不读取 Cookie、密码、全局浏览历史，也不监听其他网站或微信。没有远程代码、分析埋点、服务器或自动后台采集。扩展 API 的下载权限本身具备较广能力；本实现只跟踪本工具发起的下载 ID。

## 实现与边界

短链接在普通标签页中正常跳转，待到达已授权的抖音作品页后核对作品 ID。它不使用跨域 fetch 获取分享页，也不需要为中间的 iesdouyin.com 分享域名增加权限。

本次直达页 `/video/:id` 的首屏数据不含作品；扩展会正常打开同一作品的 `/user/self?modal_id=:id` 页面，尝试一次已实测的弹窗展示方式。仅在 URL 的作品 ID 与 `RENDER_DATA → app.videoDetail.awemeId` 严格一致时读取媒体字段。若首屏指向其他作品会直接停止，不用推荐作品替代。当前只适配本次实际观察到的网页字段和三个 CDN 域名，优先兼容的 720p H.264 MP4，也可选择 1080p。

`download.allowDownload` 是网页下载入口的状态，本工具如实显示；它不等于 CDN 实际 HTTP 访问结果，也不等于版权授权。当前样本在该字段为 false 时，普通 CDN 请求仍返回 200/206。这只能证明本样本的技术行为。使用者仍须具备保存、使用素材的权利。

不处理加密候选、付费解锁、签名生成、验证码绕过、Cookie 提取、接口反滥用规避、图片作品或 DASH 音视频合并。遇到拒绝、初始化数据不匹配、地址失效或未识别 CDN 会停止，不轮换身份规避。

完整转写由同机伴随服务调用 `scripts/transcribe_accurate.py`；大模型保存在本项目，未打包进浏览器扩展。音视频不上传至语音服务商。

这是可检查源码的开发原型，尚未选择公开发行许可证。单样本的一键下载及文案界面验收已完成，开源发布前仍需更多样本兼容性验证及跨机器安装流程。
