# UI icons

Heroicons outline icons, vendored from the official tailwindlabs/heroicons repository on 2026-10-14. MIT license is included as LICENSE. Source: https://github.com/tailwindlabs/heroicons/tree/master/optimized/24/outline

Used as local CSS masks with currentColor so light/dark themes share the same paths. No CDN or runtime dependency. ClipQuill's custom brand SVG source is in ../brand/.
