# 从抖音链接提取文案与逐句校对

当前扩展为 v0.1.5 自动启动版。不依赖轻抖，不上传音频，也不使用云端语音 API。自动识别仍不能保证 100% 准确。

## 首次安装（只做一次）

新用户解压完整的 `ClipQuill-v0.1.5-mac-arm64.zip`，双击其中“首次安装.command”。运行环境和音频工具包含在包中；程序自动下载、校验模型并配置 Chrome 连接，不用安装 Python、Homebrew 或填写扩展 ID。首次模型下载约 4.0 GiB；中断后重新双击可继续。完成后按自动打开的目录，在 Chrome 扩展管理开启开发者模式并加载该目录。

本项目已安装旧版的用户双击 `outputs/首次安装.command`，会复用本机已有模型、配对原扩展目录并迁移旧任务，然后在 Chrome 对原扩展点击“重新加载”。保留原目录与扩展存储，不要卸载旧扩展。

安装包当前适用于 Apple Silicon Mac、macOS 26 或更新版本和 Google Chrome。安装完成后可以移走解压包；保留安装后的 `Library/Application Support/ClipQuill`。

## 日常使用

1. 从 Chrome 工具栏打开“抖音视频与文案 · 本地简化版”。首次更新到 v0.1.5 需重新加载同一扩展目录，使用新增的本地助手通信权限。
2. 粘贴抖音分享链接。可选填视频中可能出现的专有名词，例如 `Claude, Opus 5.5, GPT-6 Astra`。术语会保留，换主题时请修改或清空。
3. 点击“提取文案”，保持工具页打开。本地助手自动启动或复用现有服务，随后自动处理当前视频；不需要保留终端窗口。启动失败可点击“重试启动并提取”。视频保存后，在本机完成识别、字幕时间对齐和第二模型对照。
4. 在“视频文案”中选择片段，点“回听这一句”。带 ※ 的片段是两次识别有分歧或对齐异常的地方；无标记也不代表一定正确。
5. 直接修改“这一句的文案”，核对后勾选“我已核对这一句”。任何实际文字改动都会取消该句确认。
6. 复制全文或导出 TXT / SRT。两种导出都会使用修改后的内容。未全部确认时，文件名带“待校对”；全部确认后带“已逐句核对”，不标注准确率。

原始识别稿不会覆盖。修改草稿保存在当前电脑、当前扩展的本地存储中，重新打开后点“恢复上次识别”即可找回。清除扩展数据或卸载会丢失草稿，请及时导出。原音时间戳由模型估计，仍可能需要调整；本版只支持改字，不支持编辑时间轴。

## 电脑重启后

完成首次安装后，直接打开插件并点击“提取文案”，本地助手会自动启动。服务只监听 `127.0.0.1:8766`，只接受安装程序已配对的扩展请求。关闭 Chrome 或工具页不会主动关闭已经启动的服务；识别期间请保持工具页打开，电脑休眠或关机会中断当前处理。

提取文案和失败重试会优先复用“下载 / 抖音独立导出”中的完整视频，包括过去版本的下载；文件丢失或实际大小不符时才重新下载。识别失败本身不会重复下载。改变清晰度偏好也可继续复用已有兼容视频，界面显示实际文件规格。

视频在“下载 / 抖音独立导出”。安装版原始文案、字幕、对照识别、回听音频和处理记录位于当前用户 `Library/Application Support/ClipQuill/outputs/extension-transcripts/`，不同任务分开保存。项目原有结果保留；旧用户升级时会复制到新助手。导出的校对稿在 Chrome 默认下载目录。

## 本次实测

2026-10-12，作品 `7689864994510343451`，原 5 分钟 GPT 动效视频：

- 真实 Chrome 链接到文案流程成功，本地处理用时 23.861 秒，不含下载；得到 122 个片段。
- Qwen3-ASR 1.7B 为主识别，Qwen3 ForcedAligner 对齐，Whisper Turbo 独立识别用于提示分歧。此样本 40 个片段提示重点核对，提示数不是错句数或准确率。
- “Cloud / 抽针 / 观念针 / 手中的攻击”等旧错误改善为“Claude / 抽帧 / 关键帧 / 手中的工具”。英文改善包含术语提示的帮助。
- 仍有错误和个别退步，如原始新稿把“成片”识别成“成天”、把“对我来说”识别成“对我们来说”。“成天”已在扩展草稿中对照视频字幕改为“成片”，并验证 TXT/SRT 导出同步；其余全文没有逐字验收。
- 未建立整段人工听写的参考稿，不报告整体准确率。详见 `文案精度优化验证.md`。

## 开发者依赖与旧手动方式（用户安装包已包含环境）

单独的扩展 ZIP 仅含浏览器代码；其他电脑应使用上面的完整安装包。以下仅记录开发环境和保留的手动启动方式：

- Python 3.9+ 运行本地服务，FFmpeg / ffprobe。
- Python 3.12 的 `work/asr-venv`，依赖版本见 `scripts/asr-requirements.lock.txt`。
- `work/independent-asr/qwen3-asr-1.7b-8bit` 与 `qwen3-aligner-0.6b-8bit` 模型目录。
- 原有 whisper.cpp Metal 版本、Whisper Turbo Q5_0、Silero VAD。

本版利用 Mac GPU，尚未验证 Windows、Intel Mac 或其他硬件。固定模型文件、来源和校验值见项目 `packaging/models.lock.json`。安装程序自动建立确切扩展配对；开发者手动启动才需要 `--extension-id`。`启动本地文案服务.command` 保留为开发和回退入口。

服务仍限制完整下载目录中的 MP4、同一作品 ID、匹配字节数、一小时以内的视频，一次一个任务。登录、验证码、下载拒绝仍交给正常页面处理。
