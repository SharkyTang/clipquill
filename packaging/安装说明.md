# ClipQuill 首次安装

此包用于 Apple Silicon Mac、macOS 26 或更新版本，以及 Google Chrome。其他平台尚未提供安装包。

1. 解压完整安装包，双击“首次安装.command”。Python 和音频工具已包含在包中，安装程序自动下载、校验模型并设置 Chrome 连接。首次需要联网下载约 4.0 GiB 模型，安装窗口会显示进度；中断后重新双击即可继续。
2. 安装完成会打开扩展文件夹和 Chrome 扩展管理。开启“开发者模式”，点击“加载已解压的扩展程序”，选择刚打开的文件夹。这一步用于尚未上架商店的开发版；不用填写扩展 ID 或运行命令。
3. 打开插件，粘贴链接，点击“提取文案”。本地助手按需后台启动，已经运行时直接复用。无需每次打开终端，也不要求登录电脑时常驻启动。失败时点击“重试启动并提取”。

程序安装到当前用户的 `Library/Application Support/ClipQuill`，安装包解压目录可以在安装完成后移走；不要移动已安装目录。重启电脑后仍可按按钮自动启动。语音识别使用本机模型，视频和音频不上传到语音服务。

已在原目录安装旧扩展时，请重新加载原扩展，不要卸载或清除数据。开发者提供的本机升级入口会自动保留原扩展身份并迁移旧任务；新安装包默认连接自己安装的扩展目录。若将扩展另行搬到新目录，需重新安装以更新连接配置。

本包保留依赖许可证和来源记录。它是开发版，尚未完成其他电脑的安装验收、Developer ID 签名或公证。macOS 提示阻止打开时，应按系统正常的打开流程处理，不需要关闭系统保护。开发者需在对外正式发布前完成签名、公证及新电脑验收。
